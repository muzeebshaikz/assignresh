# Mock payloads

All payloads below are **invented**. They are realistic in spirit but are NOT the real Ashby, Workday, Okta, Lumos
or Google Sheets schemas. Real integrations would replace `mappers/` and `adapters/` only.

## Ashby event `payload`
```json
{"candidate": {"id": "cand-alex", "firstName": "Alex", "lastName": "Rivera", "preferredName": null, "email": "alex.rivera@example.com"},
 "offer": {"startDate": "2026-11-16", "department": "Coaching", "employmentType": "FTE", "hiringManagerEmail": "dana.cho@betterup.co"},
 "location": {"city": "Austin", "country": "US", "remote": false},
 "shippingAddress": {"line1": "...", "line2": null, "city": "...", "state": "TX", "postalCode": "78701", "country": "US"}}
```
## Workday event `payload`
```json
{"worker": {"workerId": "WD-5521", "legalName": {"first": "Jonathan", "last": "Smyth"}, "preferredName": null,
            "contactEmail": "...", "hireDate": "2026-11-23", "managerEmail": "...", "department": "Coaching",
            "workerType": "Employee|Contractor|Intern", "workLocation": {"city": "...", "country": "US", "remote": false},
            "homeAddress": {"line1": "...", "city": "...", "state": "...", "postalCode": "...", "country": "US"}}}
```
Envelope (`SourceEvent`): `event_id`, `source`, `event_type` (`hire.created|hire.updated`), `source_version`
(monotonic per source entity), `occurred_at`, `payload`.

## Scenarios
`scenarios/S1..S8.json` are generated by `build_scenarios.py`. `setup.failures` injects faults
(`fail_first_calls`+`status` => transient; `conflict_logins` => Okta 409), `setup.mark_shipped` flags equipment as shipped.
The demo pins "today" to 2026-11-02 so validation V1/V2 are reproducible.
